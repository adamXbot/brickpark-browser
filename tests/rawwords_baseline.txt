# The accepted raw-word residue -- the baseline for the `raw_words` ctest.
#
# `gen/rawwords.md` is the census that does NOT ask the declarations: every
# 4-byte word of every emitted object whose value lands in the original image's
# .rdata/.data, with the inline-text vetoes applied (see `textish_word` in
# gen_link.py). A word in it is a word the game will dereference as a number.
# The older gate, `pointer_words`, cannot see these: a declaration that cannot
# be sized (`extern FXEntry g_game_fx[];`) makes its object invisible to it, and
# that is how 23 sound-effect names stayed raw under a gate reporting
# `raw pointer words: 0` (docs/lanes/scope-port-b11.md §3).
#
# The residue is not zero yet, so the gate is this list:
#
#   * a row NOT here, or a row whose word count GREW  -> the test FAILS;
#   * a row that shrank or vanished                   -> the test passes and
#     prints SHRUNK; tighten this file in the same commit as the fix.
#
# Most rows are owed a BOUND in the declaring game source (PORT-M11). The rest
# are false positives of a value-based census and say so; each one has a reason,
# in the spirit of `PTR_VERDICTS`. A row with no reason is open work.
#
# Format: <addr> <words> <object> str=N,sym=N,data=N   # reason
# Measured on 2026-09-12, PORT-A9, wasm32 --ilp32 closure of 68fab1d3 + A9.
# 27 objects, 107 words.
